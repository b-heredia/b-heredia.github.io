Why I built it

Many people, especially those who aren't familiar with cybersecurity threats, can become victims of malicious links by accidentally clicking websites that look legitimate. I wanted a beginner-friendly tool that helps people notice warning signs in a URL before they interact with it.

What it checks

TrustLens analyzes HTTP and HTTPS links using predefined detection rules. It looks for:

  • Suspicious URL structures
  • IP addresses used instead of a domain name
  • URL shorteners
  • Unusual domain endings

What it doesn't do

TrustLens doesn't guarantee whether a website is safe or malicious. It gives people information so they can make a more informed decision before clicking an unfamiliar link.
