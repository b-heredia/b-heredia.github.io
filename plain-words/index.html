A glossary of AI, code and design words.

PlainWords

I'm learning as I go, and these are the words I've had to look up. Each one is in plain language with an everyday example. If it helps me remember, maybe it helps you learn too.

24 words

AI agent

AI

An AI that can take steps toward a goal using tools, not just answer a question.

Think of it likeAn assistant you give a task to, who can open files and look things up until it's done.
In real techClaude Code can read files, run commands and make changes to finish a coding task.

Related: Subagent, Guardrail

API

CodeApplication Programming Interface

A set of rules that lets one app ask another app for information or to do something.

Think of it likeA waiter. You tell the waiter what you want, they tell the kitchen, and they bring back your food. You never go into the kitchen yourself.
In real techA weather app asks a weather service's API for today's forecast and shows you the answer.

Related: Flask, JavaScript

Commit

Tools

A saved snapshot of changes to a project, with a short message describing what changed.

Think of it likeSaving a checkpoint in a video game, so you can always go back to that moment.
In real techAdding a project to my portfolio was one commit: Add Agents with Guardrails project page.

Related: Git, Repository

CSS

CodeCascading Style Sheets

The language that styles a web page: colors, fonts, spacing and layout.

Think of it likeThe paint, furniture and decorations in a house.
In real techh1 { color: black; } makes every main heading black. CSS is often saved in its own file, usually called style.css, and connected to the page with <link rel="stylesheet" href="style.css">.

Related: HTML, JavaScript

Flask

Code

A small Python tool for building web apps. It lets your Python code respond when someone visits a page in their browser.

Think of it likeA restaurant host: when a visitor arrives at a certain address, Flask sends them to the right Python function, which serves up the page.
In real tech@app.route("/") tells Flask: when someone visits the home page, run the function below. Flask apps need a host that runs Python, like Render or PythonAnywhere, not GitHub Pages.

Related: API, HTML

Git

Tools

A tool that tracks every change to a project's files over time, so you can see what changed and go back if needed.

Think of it likeVersion history in Google Docs, but for code.
In real techDevelopers use Git so a whole team can work on the same project without losing anyone's work.

Related: GitHub, Commit

GitHub

Tools

A website that stores Git projects online so people can share them and work on them together.

Think of it likeGoogle Drive, but built for code and its history.
In real techThe code for this portfolio lives on GitHub at b-heredia/portfolio.

Related: Git, GitHub Pages

GitHub Pages

Tools

A free GitHub service that turns the files in a repository into a live website.

Think of it likePutting your poster in a shop window so anyone walking by can see it.
In real techThis site is published with GitHub Pages at b-heredia.github.io/portfolio.

Related: GitHub, Repository

Guardrail

AI

A limit that stops an AI, or any system, from doing things it shouldn't.

Think of it likeThe bumpers in a bowling lane: you still bowl, but the ball can't go in the gutter.
In real techMy code-reviewer agent is read-only, so it can point out problems but can't change any files.

Related: AI agent, Hook

Hallucination

AI

When an AI says something false but sounds confident about it.

Think of it likeA friend who fills in the gaps of a story with made-up details without realizing it.
In real techAn AI might invent a book or a source that doesn't exist. Always check important facts.

Related: Large language model, Prompt

Hook

Code

A small piece of code that runs automatically at a certain moment, like right before or after an action.

Think of it likeA doorbell camera that switches on by itself whenever someone walks up.
In real techMy code-reviewer has a hook that checks every command before it runs and blocks anything that would change files.

Related: Guardrail, Subagent

HTML

CodeHyperText Markup Language

The language that gives a web page its structure: headings, paragraphs, links and images.

Think of it likeThe frame and walls of a house, before any paint goes on.
In real tech<h1>Hello</h1> creates a main heading that says "Hello".

Related: Tag, CSS, JavaScript

Human-centered design

Design

Designing around the real needs, habits and feelings of the people who will use something.

Think of it likeA tailor who measures you before making a suit, instead of guessing your size.
In real techTesting The Better Question with real students before deciding what to change.

Related: Prototype, Wireframe

JavaScript

Code

The programming language that makes web pages interactive, so they respond when you click or type.

Think of it likeThe electricity in a house: it makes the lights turn on and the doorbell ring.
In real techThe strength meter in The Better Question updates as you type because of JavaScript.

Related: HTML, CSS

Large language model

AILLM

An AI trained on huge amounts of text so it can understand and write language by predicting what words come next.

Think of it likeSomeone who has read millions of books and is very good at guessing how a sentence should continue.
In real techClaude, ChatGPT and Grok are all built on large language models.

Related: Token, Hallucination

MVP

DesignMinimum Viable Product

The simplest version of a product that still solves the main problem, built to get it in front of real people and learn from them.

Think of it likeOpening a food truck with three dishes to see what people love, before building a full restaurant.
In real techVersion 1 of The Better Question was an MVP: it builds a strong prompt without live AI, so I could test the idea first and add more later.

Related: Prototype, Human-centered design

Prompt

AI

The question or instructions you give an AI.

Think of it likeOrdering at a restaurant: "something good" gets a guess, a clear order gets what you wanted.
In real tech"Explain photosynthesis to a 10th grader in 3 steps, with an example" works better than "photosynthesis?"

Related: Large language model, Hallucination

Prototype

Design

An early, working version of an idea, made to test it before building the real thing.

Think of it likeA cardboard model of a chair, made to check the shape before using wood.
In real techA clickable design in Figma, or the first version of a website shared with testers.

Related: Wireframe, Human-centered design

Repository

ToolsRepo

A project folder tracked by Git, holding all its files and their full history.

Think of it likeA binder that keeps every draft of a school project, not just the final one.
In real techAll my portfolio projects live in one repository called portfolio.

Related: Git, Commit

Subagent

AI

A specialist AI agent that a main AI hands one specific kind of task to.

Think of it likeA team lead passing a job to the person on the team who's best at it.
In real techI built four subagents in Claude Code, including a code-reviewer and a meeting-notes organizer.

Related: AI agent, Hook

Tag

CodeHTML tag

A label in angle brackets that tells the browser what a piece of content is. Most tags come in pairs: one to open and one to close.

Think of it likeLabels on storage boxes: "Photos", "Books". The label tells you what is inside before you open it.
In real tech<p>Hello</p> marks "Hello" as a paragraph. <p> opens it and </p> closes it.

Related: HTML, CSS

Token

AI

The small pieces of text an AI reads and writes. A token is often a short word or part of a longer word.

Think of it likeLego bricks of language: the AI builds sentences one brick at a time.
In real techAI usage limits and costs are often counted in tokens.

Related: Large language model

Visual Studio Code

ToolsVS Code

A free app for writing and editing code, made by Microsoft. It colors your code so it is easier to read and helps you spot mistakes.

Think of it likeMicrosoft Word, but for code instead of essays.
In real techYou can open a website folder in VS Code, edit the HTML and CSS files, and see your changes when you refresh the page.

Related: HTML, Git

Wireframe

Design

A simple sketch of a page's layout, showing where things go without colors or details.

Think of it likeA floor plan of a house: rooms and doors, no furniture yet.
In real techGray boxes that show where the header, buttons and text will sit on a new app screen.

Related: Prototype, Human-centered design
