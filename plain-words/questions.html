Does CSS have tags like HTML?

Code

No. HTML uses tags to say what something is. CSS uses rules to say how it looks.

A CSS rule has two parts: a selector (which things to style) and declarations inside curly braces (what to change).

h1 {
  color: black;
  font-size: 48px;
}

A selector can point to a tag name like h1, a class like .card, or an id like #about. So CSS doesn't have tags of its own, but it often uses HTML tag names to choose what to style.

What is Flask?

Code

A small Python tool for building web apps.

It lets your Python code respond when someone visits a page. You write a function, and Flask runs it when someone goes to a certain address on your site.

@app.route("/")
def home():
    return "Hello!"

See also: Flask, API

03

Why can't GitHub Pages run my Flask app?

Code

Because GitHub Pages only serves files that are the same for everyone. Flask needs Python running every time someone visits.

  • Static site: plain HTML, CSS, JavaScript and images. GitHub Pages hosts these for free. My portfolio is static.
  • Dynamic site: code runs on a server for each visit and can respond differently. Flask apps are dynamic.

For a Flask app, use a host that runs Python, like Render or PythonAnywhere.

See also: GitHub Pages, Flask

How do I format text, headings and lists in HTML?

Code

Wrap your words in tags. Each tag tells the browser what that text is.

<h1>Main title</h1>
<h2>Section title</h2>
<p>Some <strong>bold</strong> and <em>italic</em> words.</p>

<ul>
  <li>A bullet point</li>
  <li>Another bullet point</li>
</ul>

<ol>
  <li>Step one</li>
  <li>Step two</li>
</ol>
  • Headings: <h1> is the biggest and <h6> is the smallest. Use one <h1> per page, and pick headings by importance, not size. CSS can change the size.
  • Text: <strong> makes text bold and important, <em> makes it italic and emphasized, and <br> starts a new line.
  • Lists: <ul> makes bullets, <ol> makes numbers, and every item goes in an <li>.

See also: Tag, Element, Nesting

05

How do I add links and images in HTML?

Code

Links use <a> with an href that says where to go. Images use <img> with a src that says which picture and an alt that describes it.

<a href="https://github.com/b-heredia">My GitHub</a>
<a href="plain-words/">Plain Words</a>

<img src="images/me.jpg" alt="Briana smiling at her desk">
  • Links: use the full web address for other sites and a short path for pages on your own site. The words between the tags are what people click. Add target="_blank" to open the link in a new tab.
  • Images: <img> has no closing tag. The alt text is read aloud by screen readers and shows up if the picture doesn't load, so describe what's in the image.
  • Tip: on GitHub Pages, file names are case-sensitive. Me.jpg and me.jpg are different files.

See also: HTML, Closing tag, GitHub Pages

What's the difference between a problem ticket and an incident ticket?

IT

An incident ticket is about fixing something that's broken right now. A problem ticket is about finding out why it keeps breaking.

  • Incident: an unplanned outage or slowdown, like someone who can't log in. The goal is to get people working again fast, even with a quick workaround.
  • Problem: the hidden cause behind one or more incidents. The goal is to find the root cause and fix it so it stops happening.

Example: on Monday, three people can't connect to the Wi-Fi. That's three incident tickets, and restarting the router gets everyone back online. When it happens again every Monday, someone opens a problem ticket to find out why.

Think of it like this: the incident is putting out the fire, and the problem is finding what keeps starting it. These terms come from ITIL, a common set of practices for running IT support.
